* Taller: Máquina de Von Neumann

La máquina de Von Neumann realiza operaciones en un ciclo repetitivo de
*captación*, *decodificación* y *ejecución*. Para esto, el computador
IAS usa una memoria de 40 bits. Cuando la memoria se usa
numéricamente, el dato representa un número en complemento a 2; donde
el bit inicial corresponde al signo. Cuando la memoria se usa para el
registro de instrucciones, se divide en dos partes de 20 bits cada una. Los 8
primeros bits de cada parte corresponden al /opcode/ y los restantes
12 bits de cada parte a la /dirección (operando)/ desde la que se debe
leer o a la que se debe escribir.

** Ejercicio

En la máquina IAS, las instrucciones se dividen en dos segmentos:
i) izquierdo, desde el bit 0 a 19, y ii) derecho, desde el bit 20 al 39. Primero
se ejecuta el lado izquierdo y luego el derecho. El
contador de programa inicia en la posición $[PC] \leftarrow 300$. El conjunto de
instrucciones del computador o ISA[fn:2] está definido en la Tabla
\ref{tab:tablaISA-IAS}. A fin de terminar el programa, se agrega la
instrucción ~0x99~ que lleva al computador al estado de HALT. Conteste las
siguientes preguntas considerando la Tabla [[tab:memoria-compu]] como el
mapa de memoria de la máquina y obtenga el programa en lenguaje ensamblador y en
RTL.

*** Preguntas
   Procedmiento:
   Para la direccion $\text{0x300}$
   
   - $[PC] \leftarrow \text{0x300}$
   - $[IR] \leftarrow [[PC]]$

   - $[IR] \leftarrow \text{0x06941}$
   - $[AC] \leftarrow [AC]-\text{[0x941]}$
   - $[AC] \leftarrow \text{0x005 - 0x002}$
   - $[AC] \leftarrow \text{003}$   

   Para la dirección $\text{0x301}$

   - $[PC] \leftarrow \text{0x301}$
   - $[IR] \leftarrow [[PC]]$
   - $[IR] \leftarrow \text{[0x301]}$

   - $\text{[0x940]} \leftarrow \text{003}$

   - $[PC] \leftarrow \text{0x301}$
   - $[IR] \leftarrow [[PC]]$
   - $[IR] \leftarrow \text{[0x301]}$  
   - $[IR] \leftarrow \text{0x14000}$

   - $[AC] \leftarrow \text{006}$
   
   Para la dirección $\text{0x302}$
   
   - $[PC] \leftarrow \text{0x302}$
   - $[IR] \leftarrow [[PC]]$
   - $[IR] \leftarrow \text{[0x302]}$

   - $\text{[0x941]} \leftarrow \text{006}$
   
   - $[PC] \leftarrow \text{0x302}$
   - $[IR] \leftarrow [[PC]]$
   - $[IR] \leftarrow \text{[0x302]}$  
   - $[IR] \leftarrow \text{0x02940}$
   - $[AC] \leftarrow \text{-[0x940]}$

   Para la dirección $\text{0x303}$

   - $[PC] \leftarrow \text{0x303}$
   - $[IR] \leftarrow [[PC]]$
   - $[IR] \leftarrow \text{[0x303]}$  
   - $[IR] \leftarrow \text{0x21940}$
   - $\text{[0x940]} \leftarrow [AC]$
   - $\text{[0x940]} \leftarrow \text{-003}$   

   - $[PC] \leftarrow \text{0x303}$
   - $[IR] \leftarrow [[PC]]$
   - $[IR] \leftarrow \text{[0x303]}$  
   - $[IR] \leftarrow \text{0x99000}$
   - $[IR] \leftarrow \text{HALT}$
   
     
1. ¿Qué resultado se tiene al final en el registro del acumulador?  
   Respuesta:
   
   $[AC] \leftarrow -3$
 

2. ¿Se sobrescribe algún registro como resultado de la ejecución? Si
   es verdadero, indique qué registro y con qué valor.
   Respuesta:
   - $[940] \leftarrow -3$
   - $[941] \leftarrow 6$
   - $[AC] \leftarrow -3$

3. ¿Cuál es el valor del bit de Carry? ¿Qué operación modifica el bit?
   Respuesta:
   - $Carry = 1$

   - La operación que modifica el bit es SUB M(941)
     Aquí se hacemos que la ALU haga la siguiente operación $[AC]
     \leftarrow [AC] + Comp2([M(941)])$
     Donde tenemos que el valor de $[AC]$ es 5 o ($00000101$) y el
     valor de $M(941)$ es 2 o ($00000010$), a este mismo valor se le
     hace el complemento a 2 dando como resultado ($11111110$) y ahí
     si se va a poder hacer la operación solicitada por la dirección
     de memoria siendo esta la resta que se vería así
       00000101
     + 11111110
       --------
      100000011
     Aquí ya podemos observar que existe el carry de uno al salirse de
     nuestra arquitectura de 8 bits 

*** Código RTL

Escriba en notación de transferencia de registros el programa que
ejecuta el computador IAS.

 - $[AC] \leftarrow [940]$
 - $[AC] \leftarrow [AC] - [941]$
 - $[940] \leftarrow [AC]$
 - $[AC] \leftarrow [AC] \times 2$
 - $[941] \leftarrow [AC]$
 - $[AC] \leftarrow -[940]$
 - $[940] \leftarrow [AC]$
 - $HALT$


*** Código Assembler

Escriba el código Assembler del programa que ejecuta el computador IAS.

#+begin_src
LOAD M(940)
SUB M(941)
STOR M(940)
SHL AC,1
STOR M(941)
LOAD M(940)
NEG
STOR M(940)
HALT
#+end_src
